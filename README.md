# Fylo Landing Page

A modern and fully responsive landing page built with **HTML5** and **CSS3**. This project is based on the Fylo Landing Page challenge from Frontend Mentor and focuses on creating a clean, accessible, and responsive user interface.

## ✨ Features

- Responsive layout for desktop and mobile devices
- Modern Flexbox and CSS Grid layouts
- Hero section with call-to-action
- Feature cards section
- Productive section with custom hover effect
- Customer testimonials
- Early access subscription card
- Professional footer with social media icons
- Smooth hover animations
- Clean and semantic HTML structure

## 🛠️ Built With

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- Font Awesome
- Google Fonts
